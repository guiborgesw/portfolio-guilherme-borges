# 🎮 Guilherme Borges — Portfolio

> A pixel art developer portfolio built with React, TypeScript and styled-components.

![alt text](image.png)

## 📌 About the Project
**Guilherme Borges Portfolio** is a personal portfolio website with a pixel art aesthetic, showcasing skills, projects and professional experience through an interactive and visually unique interface.

### Features

- 🕹️ Pixel art hero section with animated background
- 🛠️ Skills section with technology icons
- 📁 Projects section with description, stack tags and links
- 🏢 Professional timeline with carousel navigation
- 📬 Contact form

## 🚀 Technologies

- **React.js** — component-based UI development
T- **ypeScript** — static typing and safer code
- **Vite** — fast development build tool
- **styled-components** — CSS-in-JS with theme support

## 💻 Running Locally

```bash
# Clone the repository
git clone https://github.com/guiborgesw/portfolio-new.git

# Navigate to the project folder
cd portfolio-new

# Install dependencies
npm install

# Start the development server
npm run dev
```

Access at: http://localhost:5173
